# A-508057

바닷속 유리 돔에서 함께 명상하는 3D 공간입니다. 브라우저에서 바로 열리고, 설치나 가입이 필요 없습니다.

주소: https://aninsong77-dotcom.github.io/a-508057/

- 링크를 열면 빛 속에서 유리 돔 안으로 들어와 방석에 앉습니다.
- 차 마시기, 종 치기, 사진 찍기를 할 수 있습니다. 위쪽 **나가기**를 누르면 빛을 타고 올라가며 끝납니다.
- 조작: 바닥을 누르거나 방향키로 움직이기, 화면을 끌어 둘러보기. PC는 1 안녕하세요, 2 합장, 3 종, 4 차, F 앉기, V 시점.
- 지금은 혼자 쓰는 화면입니다. 여러 사람이 함께 보이는 기능은 다음 단계에서 연결합니다.

3D 그림은 [three.js](https://threejs.org) 0.160.0(MIT 라이선스)으로 그리고, 열 때 인터넷(jsDelivr)에서 불러옵니다.
