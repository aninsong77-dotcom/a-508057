# 쨘 (명상 메타버스)

누구나 자유롭게 들어와 명상할 수 있는 공간입니다. 브라우저에서 바로 열리고, 설치나 가입이 필요 없습니다.

주소: https://aninsong77-dotcom.github.io/a-508057/

- 대문에서 명상할 곳을 고릅니다: 바다 · 서울 하늘(한강 / 남산) · 지구 우주. 고르지 않으면 바다로 들어갑니다.
- 유리 돔 안 방석에 앉아 함께 명상합니다. 매일 오전 9시(한국 시각)에 모두 함께 시작하고, 종을 치면 언제든 시작할 수 있습니다. 헤드셋을 쓰고 혼자 명상할 수도 있습니다.
- 들어가서도 🌀 차원이동으로 언제든 옮길 수 있습니다.
- 명상 기록은 각자의 브라우저에만 저장됩니다. 일기장 파일로 내려받고, 다른 기기의 기록을 가져와 합칠 수 있습니다.
- 자세한 사용법은 사이트 메뉴의 **사용법**에서 볼 수 있습니다.

3D 그림은 [three.js](https://threejs.org) 0.160.0(MIT 라이선스)으로 그리고, 열 때 인터넷(jsDelivr)에서 불러옵니다.
